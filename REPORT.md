1. Коммит - это сохранение изменений в Git. Staging area нужна, чтобы выбрать, какие именно изменения попадут в коммит.
2. Ветка в Git - это отдельная линия разработки, в которой можно работать над изменениями, не затрагивая основную ветку.
3. HEAD —-это указатель на текущий коммит или ветку, в которой мы сейчас находимся.
4. git fetch скачивает изменения с удалённого репозитория, но не объединяет их с текущей веткой. git pull скачивает изменения и сразу пытается объединить их с текущей веткой.
5. Файл .env нельзя добавлять в репозиторий, потому что в нём могут храниться пароли, токены и другие секретные данные.
